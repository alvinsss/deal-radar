# deal-radar

Screen the last 24 hours of new free deals — AI free credits, free VPS, cloud resources, student benefits — from official sources, deduplicated and ranked by claim value.

## What it is

A personal skill for Muse: turn a one-line request ("查今天羊毛") into a verified, ranked list of new free deals from the last 24 hours. No fabricated deals, no rehashed old ones, no ads.

## Sources (in order)

1. 懒猫 AI (lanmao.ai)
2. AIHot Token 羊毛 (aihot.news)
3. 赛博鸡蛋 (jidan.si)
4. 白嫖计 (baipiaoji.com)
5. Vendor official pages (verification source)

## Rules

- Official or trusted sources first; a secondary guide never settles a deadline — check the live page.
- Never fabricate a deal, a value, or a deadline. An unverified value stays out of counts and rankings.
- Never auto-register, auto-pay, or post externally. Claiming is always the user's decision.
